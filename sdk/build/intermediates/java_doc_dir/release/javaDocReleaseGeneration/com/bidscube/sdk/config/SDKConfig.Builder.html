      • adRequestAuthority

         SDKConfig.Builder adRequestAuthority(String authorityOrUrl)

        Override the HTTPS host (and optional port) used for all Bidscube ad request URLs.Accepts {@code host}, {@code host:port}, IPv6 {@code [addr]:port}, a full prefix such as {@code https://edge.example.com/sdk} (scheme and path are stripped), or percent-encodedinput (e.g. {@code %3A} for {@code :}). The SDK appends path {@code /sdk} and query parameters internally.

      • statsRequestAuthority

         SDKConfig.Builder statsRequestAuthority(String authorityOrUrl)

        Optional HTTPS authority for SDK statistics ({@code GET https://<host>/collect?e=…}).Same input rules as adRequestAuthority (host, host:port, pasted URL prefix).If unset or cleared, the SDK performs no stats beacons.
